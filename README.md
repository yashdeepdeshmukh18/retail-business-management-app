# Retail Business Management App

This is a React Native application built using Expo for managing small retail shop operations.

## Project Objective
To simplify daily business tasks like billing, stock management, customer pending payments, dealer payments, and transactions for small retail shops.

## Features Implemented
- Dashboard
- Billing Screen
- Stock Management
- Customer Pending Payments
- Dealer Payments
- Quotations
- Transactions
- Bottom Navigation Bar

## Technology Used
- React Native
- Expo
- JavaScript
- React Navigation

## Project Structure
- src/screens → All main screens
- src/components → Reusable UI components (Header, ItemRow, etc.)
- src/navigation → Navigation setup
